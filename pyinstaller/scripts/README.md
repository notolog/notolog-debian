# 🧪 Supporting Scripts

Located in the `scripts` directory, these tools assist with metadata and packaging:

* changelog.py - Creates a Debian changelog entry from the latest upstream `CHANGELOG.md` release.
* license-gen.py - Creates a dependency-license review draft from the build's `pip-licenses` report.
* pre-build.py - Prepares assets and runtime layout prior to PyInstaller packaging.
* audit-bundle.py - Validates executable contents, architecture, compatibility, package marker, and licence coverage.
